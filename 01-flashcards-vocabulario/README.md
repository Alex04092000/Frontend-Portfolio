# Tarjetas de vocabulario

Tarjetas interactivas para que estudiantes de inglés repasen vocabulario: se ve la palabra en inglés y, al voltear la tarjeta, la traducción y una frase de ejemplo.

**Demo en vivo:** próximamente

> Captura o GIF: pendiente (se guardará en `capturas/demo.gif`).

## Funcionalidades

- Tarjetas que se voltean con una animación 3D.
- Navegación con botones y con el teclado (flechas y barra espaciadora).
- Contador de progreso.

En desarrollo: barajar, pronunciación con voz, marcar palabras aprendidas, guardar progreso y añadir palabras propias.

## Tecnologías

- HTML semántico y accesible
- CSS (variables, transiciones 3D, flexbox)
- JavaScript sin librerías
