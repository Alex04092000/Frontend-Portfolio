# Frontend Portfolio · Alex Molina

Soy estudiante de Desarrollo de Aplicaciones Web (DAW) en Madrid y profesor de inglés. Este repositorio reúne mi camino para convertirme en desarrollador frontend con **JavaScript, TypeScript y React**.

Todos los proyectos giran alrededor del aprendizaje de idiomas: son herramientas que yo usaría con mis propios estudiantes. Así combino lo que sé enseñar con lo que estoy aprendiendo a programar.
